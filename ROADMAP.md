# Development roadmap

## Goal

Organize weekly reflections and goals.

## First working release

- [ ] Define supported inputs and expected outputs.
- [ ] Choose the implementation language.
- [ ] Implement one complete user workflow.
- [ ] Validate malformed and missing inputs.
- [ ] Add meaningful automated tests.
- [ ] Include a small sample or demonstration.
- [ ] Document setup, usage and limitations.
- [ ] Review dependencies and their licenses.
- [ ] Choose a distribution license before inviting reuse.
- [ ] Publish a tested release.

## Later improvements

Record improvements here after the first workflow works.
